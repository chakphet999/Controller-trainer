โหมดฝึก
แตะเป้า: ควบคุมจุดไปแตะเป้าหมายที่สุ่มขึ้นมา
เลี้ยงผ่านกรวย: ผ่านกรวยตามลำดับแบบซิกแซก ครบชุดได้โบนัส +3
ส่งบอล: เอียงอนาล็อกเพื่อเล็ง แล้วกด A หรือ Space ส่งให้เพื่อนร่วมทีม
เปิด/ปิดเส้นแนวส่งบอลได้ที่ปุ่ม "เส้นแนวส่งบอล" หรือกดปุ่ม Q (ปิดเส้นเพื่อฝึกเล็งด้วยความรู้สึกล้วน ๆ)
ส่งบอลมีผู้ป้องกัน: ผู้เล่นฝั่งตรงข้าม (สีแดง) ขยับสกัดเส้นทาง เพื่อนร่วมทีมก็ขยับด้วย
ส่งด้วย A (หรือ Space): บอลมีแรงดึงดูดเข้าหาเพื่อนเล็กน้อย
ส่งด้วย X: แรงดึงดูดน้อยลง ต้องเล็งเอง
บอลชนฝ่ายตรงข้ามถือว่าถูกตัด เปิด/ปิดเส้นแนวส่งได้เหมือนโหมดส่งบอลปกติ
คุมเส้นทาง: เคลื่อนจุดจากซ้ายไปขวาตามทางโค้งโดยไม่ออกนอกเส้น
ฝึกกด Skill: ดูท่าบนจอแล้วกดตามบนจอยจริง (ค้างปุ่ม LT/RB แล้วดีดหรือหมุนอนาล็อกตามลำดับลูกศร)
เลือกท่าที่อยากฝึกได้ด้วยปุ่มชิป (เลือกได้หลายท่า) หรือกด "เลือกทั้งหมด" / "เฉพาะท่า 12th"
ทิศลูกศรเป็นมุมมองหลังนักเตะ (บน = ไปข้างหน้า)
ระหว่างซ้อมในโหมดนี้ ปุ่ม A จะไม่หยุดเกม (หยุดด้วยปุ่มบนหน้าเว็บ)
ท่ามาตรฐานตามหน้า Gameplay 12th ของ FC Online: Ball Roll Drag ซ้าย/ขวา, Flair Nutmeg, Elastico Variation, Elastico Chop ซ้าย/ขวา
ท่าเสริมอ้างอิงเกมซีรีส์ EA FC (ตรวจกับในเกมอีกครั้ง): Elastico, Heel Flick, Feint Forward and Turn, Stop and Go
เพิ่มท่าเองได้ที่ตาราง SKILLS ใน script.js
ไม่มีจอยก็ทดสอบได้: ลูกศร = RS, WASD = LS, R = LT, E = RB
ฝึกป้องกัน: บังคับจุดไล่ผู้เล่นที่ครองบอล (วงกลมคือระยะแย่งบอล) กด RT วิ่งเร็ว เข้าใกล้แล้วกด B แย่งบอล ถ้ากด B ตอนอยู่ไกลจะพลาดและเสียจังหวะ
เลี้ยงหลบ: เลี้ยงบอลหลบจุดแดงที่พุ่งเข้ามาหา หลบพ้น +1 ถูกชนเสีย 2 คะแนน กด RT วิ่งเร็วช่วยหลบ
ระหว่างซ้อมโหมด Skill / ป้องกัน / เลี้ยงหลบ ปุ่ม A จะไม่หยุดเกม
Player Run (ปัดเส้นเขียว): หันหน้าหาเพื่อนที่ไฮไลต์ด้วยอนาล็อกซ้าย (LS) ค้าง LT+LB แล้วดีดอนาล็อกขวา (RS) ไปทิศของเส้นเขียวครั้งเดียว เพื่อนจะวิ่งต่อเองตามเส้นไปเรื่อย ๆ
ผิดเงื่อนไขข้อใดข้อหนึ่ง (ไม่ได้ค้างปุ่ม / หันหน้าผิดคน / ทิศไม่ตรง / หมดเวลา) นับเป็น "สั่งพลาด"
ระดับยากจะไม่แสดงเส้นเขียวล่วงหน้า บอกเป็นชื่อทิศแทน
ระดับความยาก

ปรับได้ในแต่ละโหมด (ง่าย / กลาง / ยาก) ที่ตาราง LV ใน script.js ค่าที่ปรับได้: r ขนาดเป้า/กรวย, hw ความกว้างทาง, amp ความโค้งของทาง, cones จำนวนกรวย, dist ระยะเพื่อนร่วมทีม, cs ความเร็วผู้ครองบอล, tr ระยะแย่งบอล, ds ความเร็วจุดแดง, di ช่วงเวลาเกิดจุดแดง, hm การเลี้ยวไล่, as แรงดึงดูดของบอล, nd/dd จำนวน/ความเร็วผู้ป้องกัน, pw/ph เวลาต่อคำสั่งและการแสดงเส้นเขียวของ Player Run, win เวลาต่อสเต็ปของท่า Skill (มิลลิวินาที), mag/ang ความเข้มงวดของแรงและมุมอนาล็อก สถิติสูงสุดเก็บแยกตามโหมดและระดับใน localStorage

ปุ่มควบคุม
จอย: อนาล็อกขยับจุด, ปุ่ม A เริ่ม/ส่งบอล
คีย์บอร์ด (ไว้ทดสอบ): WASD หรือลูกศร, Space เริ่ม/ส่งบอล, Shift = RT (วิ่งเร็ว), B = แย่งบอล, X = ส่งแบบดึงดูดน้อย, R = LT, T = LB, Q เปิด/ปิดเส้นแนวส่งบอล
