# FC Stick Trainer

เว็บฝึกควบคุมอนาล็อกจอยให้แม่นยำ ก่อนนำไปเล่น FC Online (แยกจากตัวเกม ไม่ได้ควบคุมเกมโดยตรง)

## โครงสร้างไฟล์
- `index.html` โครงหน้าเว็บ
- `style.css` การจัดหน้าและธีมสี (รองรับโหมดมืด/สว่างตามระบบ)
- `script.js` ตรรกะเกมและการอ่านค่าจอยด้วย Gamepad API

## วิธีรันใน VS Code
1. เปิดโฟลเดอร์นี้ใน VS Code
2. ติดตั้งส่วนขยาย Live Server แล้วคลิกขวาที่ `index.html` เลือก Open with Live Server
   (หรือดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ก็ได้)
3. ต่อจอยกับคอมพิวเตอร์ แล้วกดปุ่มบนจอยหนึ่งครั้งเพื่อให้เบราว์เซอร์ตรวจพบ

## โหมดฝึก
- แตะเป้า: ควบคุมจุดไปแตะเป้าหมายที่สุ่มขึ้นมา
- เลี้ยงผ่านกรวย: ผ่านกรวยตามลำดับแบบซิกแซก ครบชุดได้โบนัส +3
- ส่งบอล: เอียงอนาล็อกเพื่อเล็ง แล้วกด A หรือ Space ส่งให้เพื่อนร่วมทีม
  - เปิด/ปิดเส้นแนวส่งบอลได้ที่ปุ่ม "เส้นแนวส่งบอล" หรือกดปุ่ม Q (ปิดเส้นเพื่อฝึกเล็งด้วยความรู้สึกล้วน ๆ)
- คุมเส้นทาง: เคลื่อนจุดจากซ้ายไปขวาตามทางโค้งโดยไม่ออกนอกเส้น

## ระดับความยาก
ปรับได้ในแต่ละโหมด (ง่าย / กลาง / ยาก) ที่ตาราง `LV` ใน `script.js`
ค่าที่ปรับได้: `r` ขนาดเป้า/กรวย, `hw` ความกว้างทาง, `amp` ความโค้งของทาง, `cones` จำนวนกรวย, `dist` ระยะเพื่อนร่วมทีม
สถิติสูงสุดเก็บแยกตามโหมดและระดับใน localStorage

## ปุ่มควบคุม
- จอย: อนาล็อกขยับจุด, ปุ่ม A เริ่ม/ส่งบอล
- คีย์บอร์ด (ไว้ทดสอบ): WASD หรือลูกศร, Space เริ่ม/ส่งบอล, Q เปิด/ปิดเส้นแนวส่งบอล
